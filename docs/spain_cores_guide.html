1. What the code does

The Spain pipeline ingests monthly domestic petroleum product consumption published by CORES (Corporación de Reservas Estratégicas de Productos Petrolíferos) on the statistics page. The series is labelled Petroleum Product Consumption and is updated monthly as a single Excel file.

CORES xlsx → Parse (6 sheets) → Parquet database → Dashboard notebook

Layers

LayerRole
Scraper
scrapers/spain_cores.py		 Downloads oil-products-consumption.xlsx into data/raw/spain/; calls the parser.
Reference
reference/spain.py		 Workbook parsing, JODI composite specs, seasonality rollups, display labels.
Processor
processors/spain_cores_consumption.py		 Canonical columns via product_map.csv; saves spain_cores_consumption.parquet.
Update script
scripts/update_spain.py		 CLI you run after CORES publishes a new file.
Notebook
notebooks/17_spain_demand_dashboard.ipynb		 Charts: headline, seasonality, CORES vs JODI, Kayrros jet. Reads parquet only.

Unlike Korea (many CSV bundles), Spain is one workbook = full history (1996 → latest month). Each monthly run re-downloads (or uses a cached copy of) the same filename and replaces overlapping rows in parquet.

2. Source workbook

ItemDetail
File oil-products-consumption.xlsx

Frequency Monthly (typically updated around mid-month for the prior month)
Unit in file tonnes (t in parquet)
History From January 1996; current vintage includes through the latest published month

Sheets parsed

Six product sheets are melted to long form. Start (metadata) and All (wide duplicate) are ignored.

SheetStored lines (examples)Excluded from storage
LPG Bottled, Bulk, Road, Other LPG Total
Gasoline 97/95/98 RON, biogasoline, blend, aviation, other Subtotal road gasoline, Total
Gasoil Road diesel, biodiesel lines, ag diesel, heating oil, other Subtotal road diesel, Total
Kerosene Jet, Other kerosene Total
Fuel oil No. 1, No. 2, low-sulphur, other Total
Other products Lubricants, asphalt, petcoke, others Total
Native key format Each stored row uses {Sheet} | {column}, e.g. Gasoil | Road diesel. Totals and subtotals are tagged [AGG] in reference/product_map.csv and are not written to parquet.

Early years (especially 1996–1997) may have sparse sub-columns (NaN) on some sheets; those months simply omit rows for missing cells.

4. Units and products

  • Native unit: t (tonnes, as published by CORES).
  • Charts: converted to kbd via kt and analytics.units.convert_series (product-kind density).
  • Metric type: TOTDEMO (domestic demand / consumption).
  • Country code: ES.
  • Provisional flag: currently false for all rows (CORES notes data are provisional in the file metadata; not month-level yet).
  • Stored products: 27 detail lines (aggregates excluded).
  • Headline total (notebook §2): sums end-use lines; excludes the “Other products” sheet (lubes, asphalt, coke, residual).

5. How to update data (cookbook)

Run all commands from the country_oil_scraper/ folder:

cd country_oil_scraper

What do you want to do?

GoalCommandWhat happens
Monthly refresh (usual) 
python scripts/update_spain.py
 Downloads xlsx if missing or size changed; parses full workbook; upserts all month×product keys into parquet.
Force re-download 
python scripts/update_spain.py --force
 Ignores cache and fetches a fresh copy from CORES.
Offline / manual file 
python scripts/update_spain.py --no-download --local-file data/raw/spain/oil-products-consumption.xlsx
 Parses your local copy without hitting the network.
First-time or full rebuild 
python scripts/update_spain.py --bootstrap
 Rebuilds parquet from one workbook (same parse as routine run).
No network, use cached xlsx 
python scripts/update_spain.py --no-download
 Uses latest file in data/raw/spain/; upserts if parquet exists.
After any update Restart the notebook kernel and re-run from §1 in notebooks/17_spain_demand_dashboard.ipynb.

Log messages to watch for

  • Built 7,991 rows, 1996-01-01 -> 2026-03-01, 27 products — typical bootstrap size (varies slightly with NaNs).
  • Upsert: N replaced, M appended — revised months/products updated in parquet.
  • Using cached workbook — skipped download (use --force after CORES update).

Also update JODI (for §7 charts)

python scripts/update_jodi.py

JODI often lags national agencies by one month.

Tests

python -m pytest tests/test_spain_cores.py -q

Requires data/raw/spain/oil-products-consumption.xlsx present.

7. JODI and Kayrros comparisons

JODI (§7)

Composites sum stored CORES subs before comparing to JODI. You can narrow natives later in reference/spain.py (GASOLINE_JODI_NATIVES, GASOIL_JODI_NATIVES, etc.).

PanelCORES sideJODI code
GasolineAll stored gasoline-sheet lines (incl. bio, aviation)GASOLINE
Gasoil / dieselAll stored gasoil-sheet lines (incl. biodiesel, heating)GASDIES
Jet fuelKerosene | JetJETKERO
Other keroseneKerosene | Other keroseneX_OTHKERO
LPGAll four LPG channelsLPG
Fuel oilAll four fuel-oil gradesRESFUEL

Kayrros (§8)

  • Requires kayros/jet_fuel/data/jet_fuel.duckdb (sibling repo under workspace).
  • Uses get_consumption(scope_type='country', scope='Spain', …).
  • Compares flight-derived burn to CORES jet kerosene deliveries — not a strict identity.
